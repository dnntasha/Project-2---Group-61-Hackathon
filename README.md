# Computer Science 343 Project 2 - Group 61

## Basics

### Installing dependencies

`Server dependencies`

To install the necessary server dependencies, run the following instructions from the root of the project.

```bash
cd server
npm install
```

`Client dependencies`

To install the necessary client dependencies, run the following instructions from the root of the project.

```bash
cd client
npm install
```

### Running the project

`Initialising the backend:`

- Navigate to `/server` and run `npm run dev`

`Initialising the frontend:`

- Navigate to `/client ` and run `npm run dev`

`Accessessing the project:`

- on a browser go to `http://localhost:3000/`

### Project info

Backend: `http://localhost:5000`

Frontend: `http://localhost:3000/`
